# APEX v0.2.0 Preview

영어 화면과 언어 선택, 첫 실행 설정 창, 앱 안에서 하는 AI 연결 설정을 추가한 프리뷰입니다. 분석 엔진의 지원 범위는 v0.1.4와 같습니다.

## 새 기능

- **한국어·English 화면:** 첫 실행은 운영체제 언어를 따르고(한국어가 아니면 영어), 설정 → 언어에서 바꾸면 재시작 없이 적용됩니다. 보고서 레이블은 사건을 만들 때의 언어를 따릅니다.
- **첫 실행 설정 창:** 처음 실행하면 작은 설정 창이 먼저 열려 언어 → 분석자 이름 → AI 연결 → OCR·음성 인식 → 서버 계정 순서로 기본값을 받습니다. 언어 외에는 건너뛸 수 있고, `시작`을 누르면 본 앱이 열립니다. 왼쪽 단계 목록의 체크는 실제로 값이 설정된 단계에만 붙습니다.
- **앱 안 AI 연결:** 설정 창이나 본 앱의 설정 → AI 연결에서 접속 주소, 모델 이름, API 키를 저장합니다. 키는 운영체제의 자격 증명 보호(macOS 키체인, Windows DPAPI)로 암호화해 저장하고 화면에 다시 표시하지 않습니다. 암호화를 쓸 수 없는 환경에서는 저장하지 않습니다.
- **분석자 이름 기본값:** 설정한 이름이 새 사건 대화상자에 미리 채워집니다.

## 업데이트할 때 알아둘 점

- 이미 앱을 쓰던 경우에도 업데이트 후 첫 실행에 설정 창이 한 번 열립니다. 기존 사건과 증거 데이터는 그대로입니다.
- `APEX_DESKTOP_AI_CONFIG` 환경변수로 AI를 설정해 쓰던 경우 그 값이 계속 우선하며, 앱 화면에서는 저장·삭제를 받지 않습니다.
- AI 연결을 저장하거나 삭제하면 분석 엔진을 다시 시작합니다. 어느 사건이든 분석 작업이 실행 중이면 저장·삭제를 받지 않습니다.
- 접속 주소는 `https://`만 받습니다(`localhost`, `127.0.0.1` 제외). 연결 테스트 기능은 없으므로 저장 성공이 제공자 연결 성공을 뜻하지는 않습니다.
- 자동 업데이트는 지원하지 않습니다. 기존 v0.1.4 파일을 새 버전으로 교체하세요.

## 설치 및 최초 실행

| 환경 | 설치 파일 | 압축 파일 |
| --- | --- | --- |
| Windows x64 | APEX-0.2.0-Windows-x64.exe | — |
| macOS Apple Silicon | APEX-0.2.0-macOS-arm64.dmg | APEX-0.2.0-macOS-arm64.zip |
| macOS Intel | APEX-0.2.0-macOS-x64.dmg | APEX-0.2.0-macOS-x64.zip |

**Apple 공증과 Developer ID 서명은 없는 프리뷰입니다.** ad-hoc 서명은 앱 번들의 무결성을 위한 것이며 개발자 인증이나 Apple 공증을 대신하지 않습니다. 최초 실행 시 macOS가 개발자를 확인할 수 없다고 경고할 수 있습니다. 출처와 체크섬을 확인한 뒤 시스템 설정 → 개인정보 보호 및 보안 → 해당 APEX 앱의 '확인 없이 열기'로 승인하세요. 관리 정책으로 제한되는 기기는 관리자 승인이 필요할 수 있습니다.

DMG의 APEX.app을 응용 프로그램 폴더로 복사한 뒤 실행하세요. M1~M4 등 Apple Silicon은 arm64, Intel Mac은 x64를 사용합니다. Python·Node.js를 별도로 설치할 필요는 없습니다.

Windows는 기존처럼 서명 없는 프리뷰이며 SmartScreen 경고가 나타날 수 있습니다.

## 검증 범위

검증 보고서와 build-provenance.json은 이 릴리스의 정확한 소스 커밋·Actions 실행·자산 해시를 기록합니다. 모든 native 빌드와 DMG/ZIP 기동 검증이 성공한 경우에만 게시합니다. Apple Gatekeeper 승인이나 공증 통과로 표시하지 않습니다.

새 기능에서 확인한 것과 확인하지 못한 것은 다음과 같습니다.

- 확인: macOS에서 소스 빌드로 설정 창의 전체 흐름, AI 연결의 저장·삭제와 엔진 재시작, 설정 완료 후 재실행을 직접 실행해 확인했습니다. 프론트엔드 자동 테스트 237개가 통과했습니다.
- 미확인: Windows에서 설정 창과 키 저장을 직접 사용해 보는 검증은 하지 못했습니다. 릴리스 CI는 Windows에서 테스트, 런타임 확인, 설치 파일 생성까지 확인하며, macOS 설치본의 기동 검사도 설정 창을 거치지 않고 본 앱 창으로 확인합니다.
- 미확인: 분석 작업이 실제로 실행 중일 때 AI 연결 저장이 거부되는 동작은 자동 테스트로만 확인했습니다.
- 영어 화면은 설치본이 아닌 개발 빌드에서 확인했습니다. README와 문서, AI 응답 언어, 엔진·명령줄 메시지, 예시 데이터는 번역하지 않았고, 일부 영어 문구(단수·복수 표현 등)는 다듬을 부분이 남아 있습니다.

폴더 증거의 전체 이미지 해시 미지원, 빠른 분석의 부분 결과 표시 등 분석 기능의 기존 범위는 그대로입니다.
