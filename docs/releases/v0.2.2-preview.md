# APEX v0.2.2 Preview

APEX 서버에 로그인하면 API 키 없이 서버를 거쳐 Kimi로 AI 분석을 받을 수 있습니다. 실제 엔진과 화면으로 다시 점검해 찾은 결함 36건도 함께 고쳤습니다.

## 새 기능

- **APEX 서버 로그인:** 계정 패널에서 서버 주소, 이메일, 비밀번호, 테넌트 ID로 로그인합니다. 세션은 만료 전에 자동으로 갱신됩니다. 네트워크가 끊기면 '다시 연결 중'으로 표시하고 30초 뒤 다시 시도합니다. 서버가 세션을 끝내면 만료 안내가 나옵니다. 로그아웃하면 서버의 세션도 폐기합니다.
- **'APEX 서버' AI 연결:** AI 연결에서 'APEX 서버'와 '직접 연결'을 고를 수 있고, 새 연결은 'APEX 서버'가 기본입니다. 이 방식은 앱에 키를 저장하지 않습니다. Kimi 키는 서버에만 있고, 앱은 로그인 토큰으로 서버에 요청합니다. 기본 모델은 `kimi-k3.1-pro`입니다. 결과에는 응답한 모델과 거친 서버 주소가 기록됩니다. 로그인하지 않았으면 로그인 안내가 나옵니다. 기존 직접 연결(OpenAI 호환 주소와 키)도 그대로 쓸 수 있습니다.
- **서버 LLM 서빙:** APEX 서버(`apex_backend`)에 `POST /llm/v1/chat/completions`를 추가했습니다. 서버 운영자는 [LLM 서빙 문서](../backend/llm-serving/README.md)를 참고하세요.

## 고친 문제

### 엔진과 앱 수명

- 앱을 종료해도 엔진이 남거나, 같은 데이터 폴더에 엔진 2개가 동시에 뜰 수 있었습니다.
- 작업 중에 메인 창을 닫은 뒤 종료를 취소하면 창 없는 앱이 남았습니다.
- 앱이 실행 직후 안내 없이 종료되는 경로가 2개 있었습니다. 엔진이 준비되지 않으면 "엔진 시작 중" 표시가 끝없이 이어졌습니다.
- AI 분석이 300초에서 연결 오류로 끊겼습니다.
- AI 연결 설정을 저장·삭제한 뒤 엔진 재시작이 실패해도 성공으로 표시했습니다.
- AI API 키가 증거를 처리하는 외부 도구에 환경변수로 전달됐습니다.

### 증거 등록과 분석

- E01·VHD·VHDX 이미지를 고르면 등록이 실패할 수 있다는 경고가 잘못 떴습니다.
- 폴더 증거를 등록할 때 지원하지 않는 해시를 기본으로 요청했습니다.
- `.001` 원시 이미지를 디스크 이미지가 아닌 파일 1개로 처리했습니다. 분할 이미지 세트(`a.001`, `a.002`…)는 첫 조각만 열던 것을, 이제 작업 전에 거부하고 조각을 순서대로 합치라고 안내합니다.
- 폴더 추가 분석이 취소·실패했거나, 하위 폴더를 아직 나열하지 않았거나, 읽을 수 없는 폴더인데도 완료로 표시되어 다시 분석되지 않았습니다.
- 인덱스가 없는 증거를 검색·타임라인으로 조회하면 경고 없이 0건으로 나왔습니다. 이제 인덱스가 없거나 실패했으면 경고를 표시합니다.
- 분석 도구가 대상 유형을 확인하지 않아 실패하거나 빈 결과를 보여 줬습니다.
- 이름이 맞지 않는 음성 파일(예: m4a 내용의 `voice.dat`)을 STT가 거부했습니다. 이제 확장자 대신 실제 음성 스트림이 있는지로 판단합니다.

### STT 증거 격리

- STT 작업의 디코더가 재생목록(hls, concat, dash 등)을 따라 선택한 증거 밖의 파일을 읽을 수 있었습니다. 이제 디코딩·프레임 추출·ffprobe 모두 파일 프로토콜만 허용하고, 다른 파일을 참조하는 형식은 거부합니다.
- 손상된 패킷 하나에서 디코딩이 멈춰 뒤쪽 오디오가 표시 없이 빠졌습니다. 이제 손상된 패킷만 건너뛰고 결과를 '부분 결과'로 표시합니다.
- 디코딩에도 작업 제한 시간이 적용됩니다. 디코딩한 오디오가 2시간을 넘으면 거부합니다.

### 보관 이력과 보고서

- 보관 이력 항목을 선택하면 500 오류가 나 정정 기능에 들어갈 수 없었습니다.
- 보관 이력 목록의 순서 열이 모든 행에 `—`로 표시됐습니다. 이제 원장 순번을 표시합니다.
- 보관 기록이 동시에 겹치면 내보낸 파일이 EXPORTED 기록 없이 남을 수 있었습니다.
- API로 엔진 전용 보관 이벤트(HASH_VERIFIED 등)를 추가할 수 있었습니다.
- 반려된 보고서의 새 버전을 승인·반려할 수 없었습니다(409).

### 화면 상태

- 작업 하나가 끝날 때마다 목록이 1페이지로 돌아가고 선택이 풀렸습니다.
- 작업 상태 확인이 한 번 실패하면 결과 표가 사라진 채 돌아오지 않았습니다.
- 작업 실행 오류가 페이지 오류 칸을 함께 써서 사라지거나 보이지 않았습니다.
- 작업 상태 표시가 실제 상태와 어긋나던 곳을 고쳤습니다.
- 검색 화면이 모드를 바꿀 때 이전 검색어를 다시 실행했고, 빈 검색어로도 검색을 보냈습니다.
- 입력 검증, 내보내기, Electron 셸의 작은 불일치를 고쳤습니다.

## 업데이트할 때 알아둘 점

- 'APEX 서버' AI 연결을 쓰려면 Kimi 키가 설정된 APEX 서버의 주소와 계정이 필요합니다. 서버 주소는 `https://`여야 하며, `http://`는 `localhost`와 `127.0.0.1`만 허용합니다. 서버가 없으면 직접 연결을 계속 쓰세요.
- 로그인 토큰은 앱 메모리에만 있어서 앱을 다시 켜면 다시 로그인해야 합니다.
- 'APEX 서버' 연결의 기본 제한 시간은 120초이며, 100초보다 짧게 설정할 수 없습니다.
- 자동 업데이트는 지원하지 않습니다. 기존 v0.2.1 파일을 새 버전으로 교체하세요. 기존 사건과 증거 데이터는 그대로입니다.

## 설치 및 최초 실행

| 환경 | 설치 파일 | 압축 파일 |
| --- | --- | --- |
| Windows x64 | APEX-0.2.2-Windows-x64.exe | — |
| macOS Apple Silicon | APEX-0.2.2-macOS-arm64.dmg | APEX-0.2.2-macOS-arm64.zip |
| macOS Intel | APEX-0.2.2-macOS-x64.dmg | APEX-0.2.2-macOS-x64.zip |

**Apple 공증과 Developer ID 서명은 없는 프리뷰입니다.** ad-hoc 서명은 앱 번들의 무결성을 위한 것이며 개발자 인증이나 Apple 공증을 대신하지 않습니다. 최초 실행 시 macOS가 개발자를 확인할 수 없다고 경고할 수 있습니다. 출처와 체크섬을 확인한 뒤 시스템 설정 → 개인정보 보호 및 보안 → 해당 APEX 앱의 '확인 없이 열기'로 승인하세요.

DMG의 APEX.app을 응용 프로그램 폴더로 복사한 뒤 실행하세요. Apple Silicon은 arm64, Intel Mac은 x64를 사용합니다. Windows는 서명 없는 프리뷰이며 SmartScreen 경고가 나타날 수 있습니다.

## 검증 범위

- 확인: macOS의 실제 Electron 앱에서 로그인, 자동 갱신, 로그아웃 시 서버 세션 폐기, 서버 쪽 폐기 후 만료 안내, 잘못된 비밀번호와 서버 불통 오류를 확인했습니다. 'APEX 서버' 연결로 AI 도우미 답이 서버를 거쳐 오는 것과, 엔진 데이터와 환경에 토큰이 남지 않는 것을 확인했습니다.
- 확인: 실제 Kimi 키를 넣은 APEX 서버에서 로그인 후 `kimi-k3.1-pro` 호출이 성공했고, 토큰 없는 호출은 401이었습니다. 서버 로그에 키는 남지 않았습니다.
- 확인: STT는 실제 화면과 엔진에서 WAV, m4a, 확장자 없는 음성 파일로 확인했습니다. 수정한 결함은 각각 수정 전에 실패하는 테스트나 실제 엔진·Electron 재현으로 확인했습니다. 자동 테스트는 Python 1118개와 프론트엔드 354개가 통과했습니다.
- 미확인: 앱에서 실제 Kimi까지 이어지는 전체 경로는 가짜 Kimi 서버로 확인했습니다. 실제 Kimi 호출은 서버 단독으로만 확인했습니다.
- 미확인: Windows에서 설치본을 직접 사용하는 검증은 하지 못했습니다. 릴리스 CI는 Windows에서 테스트, 런타임 확인, 설치 파일 생성까지 확인합니다.

## 이번 릴리스에서 다루지 않은 범위

- APEX MCP 서버는 아직 APEX 서버의 LLM을 쓰지 않습니다.
- 서버에 사용자별 호출 제한과 사용량 집계가 없습니다.
- 검색은 파일 이름·경로·아티팩트 정보만 대상으로 하며 파일 내용은 검색하지 않습니다.
- APFS 볼륨은 읽지 못합니다. 경고와 부분 결과로 표시합니다.
