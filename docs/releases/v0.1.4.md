# APEX v0.1.4 Preview

macOS에서 개발자를 확인할 수 없어 최초 실행이 차단되는 문제를 해결하기 위한 배포 업데이트입니다. 이 릴리스 노트는 `Signed desktop release` 검증이 모두 통과한 뒤 게시됩니다.

- macOS arm64/Intel 앱과 동봉된 Python 분석 런타임을 Developer ID로 서명합니다.
- Apple 공증과 앱/DMG 티켓 부착을 적용합니다. ZIP에도 공증된 앱을 포함합니다.
- 실제 DMG/ZIP 내부의 서명, Team ID, 아키텍처, 버전과 Gatekeeper 검사를 통과한 파일만 게시합니다.
- 서명된 ZIP의 분석 엔진으로 기존 런타임 기동·분석 검사를 다시 실행합니다.
- `SHA256SUMS.txt`, `build-provenance.json`, 아키텍처별 macOS 검증 보고서를 함께 제공합니다.

분석 엔진과 화면 기능은 v0.1.3과 같습니다. 기존 v0.1.3 파일에 소급 적용되지 않으므로 새 설치 파일을 내려받아 설치해야 합니다. Apple Silicon(M1~M4 등)은 `arm64`, Intel Mac은 `x64` 파일을 선택합니다.

Windows x64 설치 파일은 서명 없는 프리뷰이며 SmartScreen 경고가 나타날 수 있습니다. 자동 업데이트는 지원하지 않습니다. 서명·공증은 배포 파일의 출처와 Apple 검사 상태에 대한 확인이며, 포렌식 분석 결과의 정확성이나 모든 Mac 환경에서의 동작을 보증하지 않습니다.
