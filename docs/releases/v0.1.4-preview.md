# APEX v0.1.4 Preview

macOS v0.1.3에서 앱을 열 때 '손상되었기 때문에 열 수 없습니다'가 표시되던 배포 문제를 수정한 프리뷰입니다.

## 수정 사항

- 인증서가 없으면 서명을 생략하던 패키징을 명시적 ad-hoc 서명으로 변경했습니다.
- 인증서 없는 프리뷰에서 Hardened Runtime을 끄고, Developer ID·Apple 공증 배포 설정과 분리했습니다.
- 실제 DMG와 ZIP 내부 앱의 서명, 네이티브 파일, 버전, 아키텍처를 검사합니다.
- 배포되는 ZIP의 Python 엔진으로 실제 분석 검사를 실행하고, DMG·ZIP의 Electron 화면과 preload IPC → 분석 엔진 연결까지 기동 검사합니다.
- DMG에 최초 실행 안내를 포함하고 SHA256SUMS.txt·빌드 출처·Mac 아키텍처별 검증 보고서를 제공합니다.

## 설치 및 최초 실행

| 환경 | 설치 파일 | 압축 파일 |
| --- | --- | --- |
| Windows x64 | APEX-0.1.4-Windows-x64.exe | — |
| macOS Apple Silicon | APEX-0.1.4-macOS-arm64.dmg | APEX-0.1.4-macOS-arm64.zip |
| macOS Intel | APEX-0.1.4-macOS-x64.dmg | APEX-0.1.4-macOS-x64.zip |

**Apple 공증과 Developer ID 서명은 없는 프리뷰입니다.** ad-hoc 서명은 앱 번들의 무결성을 위한 것이며 개발자 인증이나 Apple 공증을 대신하지 않습니다. 최초 실행 시 macOS가 개발자를 확인할 수 없다고 경고할 수 있습니다. 출처와 체크섬을 확인한 뒤 시스템 설정 → 개인정보 보호 및 보안 → 해당 APEX 앱의 '확인 없이 열기'로 승인하세요. 관리 정책으로 제한되는 기기는 관리자 승인이 필요할 수 있습니다.

DMG의 APEX.app을 응용 프로그램 폴더로 복사한 뒤 실행하세요. M1~M4 등 Apple Silicon은 arm64, Intel Mac은 x64를 사용합니다. Python·Node.js를 별도로 설치할 필요는 없습니다. 기존 v0.1.3 파일은 새 버전으로 교체해야 합니다.

Windows는 기존처럼 서명 없는 프리뷰이며 SmartScreen 경고가 나타날 수 있습니다. 자동 업데이트는 지원하지 않습니다.

## 검증 범위

검증 보고서와 build-provenance.json은 이 릴리스의 정확한 소스 커밋·Actions 실행·자산 해시를 기록합니다. 모든 native 빌드와 DMG/ZIP 기동 검증이 성공한 경우에만 게시합니다. Apple Gatekeeper 승인이나 공증 통과로 표시하지 않습니다.

이번 변경은 배포·기동 검사에 관한 것입니다. 폴더 증거의 전체 이미지 해시 미지원, 빠른 분석의 부분 결과 표시 등 분석 기능의 기존 범위는 그대로입니다.
