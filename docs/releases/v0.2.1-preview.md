# APEX v0.2.1 Preview

실제 디스크 이미지로 엔진과 화면을 끝까지 실행해 찾은 결함을 고친 수정 릴리스입니다. 새 기능은 없습니다.

## 고친 문제

- **볼륨이 비어 보이던 문제:** 기본값이던 "빠른 초기 분석"이 디스크 이미지의 `/volume-N`을 한 단계로 세어, 단일 볼륨 이미지를 포함한 모든 디스크 이미지에서 볼륨을 열면 아무것도 보이지 않았습니다. 이제 깊이는 각 볼륨의 파일시스템 루트부터 셉니다. 빠른 분석에서 펼치지 않은 폴더는 열거나 트리에서 펼칠 때 그 폴더만 자동으로 분석합니다. 분석 범위 기본값은 "전체 분석"으로 바꿨습니다.
- **exFAT 시각 오류:** exFAT에 기록된 UTC 오프셋을 무시하고 분석 PC의 시간대를 적용해, 같은 증거라도 PC마다 시각이 달라졌습니다(확인한 사례에서 18시간 차이). 이제 디렉터리 엔트리에 기록된 오프셋을 적용하고, 원래의 로컬 시각과 오프셋을 메타데이터에 함께 남깁니다.
- **파티션 단위 exFAT 이미지 미인식:** 파티션 표 없이 볼륨 하나만 떠낸 exFAT 이미지를 MBR로 잘못 읽어 등록 후 분석할 수 없었습니다.
- **미할당 영역 카빙 실패:** APFS·포맷되지 않은 파티션·일반 파일이 있으면 오류(HTTP 500)로 끝났고, HFS+ 볼륨이 있으면 다른 볼륨까지 카빙하지 못했습니다. 이제 읽을 수 없는 볼륨은 건너뛰고 `VOLUME_SKIPPED` 경고로 남깁니다.
- **파일시스템 이름 오표기:** exFAT이 `TSK_FS_TYPE_10`, HFS+가 `TSK_FS_TYPE_4096`으로 보였고 ext2/3/4가 다른 이름으로 대응되어 있었습니다.
- **FAT 시각 신뢰도 과장:** 시간대를 기록하지 않는 FAT 시각을 타임라인에서 "UTC 출처·높음"으로 표시했고, 날짜만 있는 접근 시각을 자정으로 보여 줬습니다. 이제 시간대 신뢰도는 "낮음", 접근 시각은 일 단위 정밀도로 표시합니다.
- **새 보고서가 목록에 보이지 않던 문제**를 고쳤습니다.
- **검색 결과 표시:** 파일 결과의 출처가 "경로 정보 없음"으로 보이던 문제와, 미디어·브라우저 결과가 "Windows 아티팩트"로 표시되던 문제를 고쳤습니다.

## 업데이트할 때 알아둘 점

- 이미 인덱싱한 증거의 시각과 파일시스템 이름은 자동으로 바뀌지 않습니다. 파일 분석을 다시 실행하면 새 해석이 적용됩니다.
- 분석 범위 기본값이 "전체 분석"이 되어 큰 이미지에서는 첫 분석이 더 오래 걸릴 수 있습니다. 빠른 분석은 계속 선택할 수 있습니다.
- 자동 업데이트는 지원하지 않습니다. 기존 v0.2.0 파일을 새 버전으로 교체하세요. 기존 사건과 증거 데이터는 그대로입니다.

## 설치 및 최초 실행

| 환경 | 설치 파일 | 압축 파일 |
| --- | --- | --- |
| Windows x64 | APEX-0.2.1-Windows-x64.exe | — |
| macOS Apple Silicon | APEX-0.2.1-macOS-arm64.dmg | APEX-0.2.1-macOS-arm64.zip |
| macOS Intel | APEX-0.2.1-macOS-x64.dmg | APEX-0.2.1-macOS-x64.zip |

**Apple 공증과 Developer ID 서명은 없는 프리뷰입니다.** ad-hoc 서명은 앱 번들의 무결성을 위한 것이며 개발자 인증이나 Apple 공증을 대신하지 않습니다. 최초 실행 시 macOS가 개발자를 확인할 수 없다고 경고할 수 있습니다. 출처와 체크섬을 확인한 뒤 시스템 설정 → 개인정보 보호 및 보안 → 해당 APEX 앱의 '확인 없이 열기'로 승인하세요.

DMG의 APEX.app을 응용 프로그램 폴더로 복사한 뒤 실행하세요. Apple Silicon은 arm64, Intel Mac은 x64를 사용합니다. Windows는 서명 없는 프리뷰이며 SmartScreen 경고가 나타날 수 있습니다.

## 검증 범위

- 확인: macOS에서 직접 만든 디스크 이미지로 엔진을 실행해 결과를 원본과 대조했습니다. MBR(확장·논리 파티션 포함), GPT, 파티션 표 없는 이미지와 FAT16·FAT32·exFAT·HFS+·NTFS, E01·VHD·VHDX, 폴더를 사용했습니다. 실제 화면에서도 빠른 분석 → 볼륨 → 하위 폴더 탐색, 검색, 보고서 작성·승인·내보내기를 확인했습니다. 자동 테스트는 Python 914개와 프론트엔드 239개가 통과했습니다.
- 미확인: Windows에서 설치본을 직접 사용하는 검증은 하지 못했습니다. 릴리스 CI는 Windows에서 테스트, 런타임 확인, 설치 파일 생성까지 확인합니다.
- exFAT 시각 보정은 macOS가 만든 exFAT으로 확인했습니다. Windows가 포맷한 exFAT은 직접 확인하지 않았습니다.

## 이번 릴리스에서 다루지 않은 범위

- 검색은 파일 이름·경로·아티팩트 정보만 대상으로 하며 파일 내용은 검색하지 않습니다.
- APFS 볼륨은 읽지 못합니다. 경고와 부분 결과로 표시합니다.
- FAT 시각은 여전히 분석 PC의 시간대로 해석합니다. 이번 릴리스에서는 그 사실을 신뢰도 표시에만 반영했습니다.
- 삭제된 파일은 뷰어에서 내용을 볼 수 없습니다. 삭제 파일 복구는 지원합니다.
